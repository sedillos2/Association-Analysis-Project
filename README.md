# Association Analysis Project
This project focuses on generating frequent item sets and association rules using a grocery transactions dataset containing the grocery shopper's member number, date the item was purchased, and item description.

# Overview
The grocery transactions data is cleaned and transformed from raw data into transactional data, then a exploratory data analysis is performed, then association rules are run to determine what insights could be shared with stakeholders.

# Methods
Data preprocessing
Exploratory data analysis 
Frequent item sets generated using Apriori algorithm
Ran association rules

# Key Findings
One piece of information I would share with my stakeholders is to not expend energy analyzing an antecedent consequent relationship where the consequent is whole milk. Customers are buying it regardless of other grocery items, so focus on other predictive relationships, like researching the relationship between (rolls/buns) and (other vegetables).
